## Netlify configuration

Added [netlify.toml](../netlify.toml). It publishes only `dist/`; skills, prompts, and concept images stay in the public repository but are absent from the current website build. [Netlify Vite guidance](https://docs.netlify.com/build/frameworks/framework-setup-guides/vite/)

```toml
[build]
  command = "bun run build"
  publish = "dist"

[build.environment]
  BUN_VERSION = "1.2.17"
  BUN_FLAGS = "--frozen-lockfile"
  NODE_VERSION = "24"

[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200
```

Bun matches `packageManager`; Node 24 satisfies the installed Vite requirement (`^20.19.0 || >=22.12.0`). Netlify exposes these runtime and install controls. [Dependency configuration](https://docs.netlify.com/build/configure-builds/manage-dependencies/)
