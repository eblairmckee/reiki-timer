# React best practices

Use this group for React code in the target app. Follow that app's installed versions, compiler configuration, data layer, and build tools. Read the applicable guidance in [rules/](rules/), choosing topic files and sections for the affected code. Check type and state contracts before changing an implementation.

For performance work, establish the bottleneck, prioritize waterfalls and bundle loading, and compare the result afterward. Preserve public behavior, accessibility, and type safety. Treat example impact figures as hypotheses to measure in this application.

Apply framework, server, and library examples where those technologies are installed. Check version and browser support for newer APIs, and use the application's existing equivalents. Match memoization to the compiler configuration and measured work; preserve Effect dependencies, cleanup, and current async results.
