# Data display

## Side by side, easy to decide

Keep comparable values visible together in aligned rows/columns so decisions do not depend on recalling another view. Review whether units, scopes and periods match.

## Digits align, differences shine

Use consistent units, separators and precision for comparable values. Use right-aligned tabular numerals in comparison tables; do not force table alignment onto every countdown. Keep formatting/localization with the appropriate data owner.

## Plot with purpose

Match charts to the question: lines for trends, bars for comparing amounts. Show clear units, scales and series identification. Check misleading truncation and meaningful non-color distinctions; provide an accessible way to understand values. Read the status rule only when missing/freshness/loading states are relevant.
