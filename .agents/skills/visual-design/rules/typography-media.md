# Typography and media

## Type sets the tiers

Use a small, consistent set of roles, sizes and weights so reading order reflects importance. Preserve Bona Nova SC for headings, countdowns and field labels; Cabin for dialog body/actions, descriptions and summary copy. Review hierarchy with actual long content and enlarged text, not only placeholder labels.

Use Hugeicons consistently. Icon-only controls need useful accessible names; visible labels and context must communicate the action. Preserve useful font fallbacks, stable media dimensions and appropriate alternative text. Load what the view needs; investigate measured delivery/rendering problems before broad optimization.
