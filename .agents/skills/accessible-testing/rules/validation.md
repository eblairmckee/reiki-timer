# Application and browser validation

Run the app's declared verification scripts and the scoped [compiler and code checks](../../typescript/rules/checks.md) appropriate to the change.

For a runnable interface, inspect the affected flow in the available browser or component preview. Check keyboard use, a narrow layout, and important states. Exercise the changed form, navigation, media, or gesture contract with representative content and supported inputs. Check reduced motion, zoom, or theme behavior when the change affects them. Automated axe checks supplement direct interaction review when available.
