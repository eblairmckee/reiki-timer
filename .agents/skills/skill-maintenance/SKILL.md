# Skill writing and maintenance

Write instructions that let a fresh agent perform the current task correctly. Use the installed Skill Creator for skill structure and tooling, and read the applicable repository standards in [rules/](rules/).

Inspect the existing owner and its callers before editing. Keep each instruction at one maintained owner, adapt imports to the application's actual contracts, and validate the changed guidance and its references. Explain the scope and evidence of the review.
