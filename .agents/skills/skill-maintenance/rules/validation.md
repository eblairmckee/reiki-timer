# Reviewing instruction changes

Review the result as an agent with no conversation history: the trigger, inputs, decisions, required resources, and completion conditions should be clear. Check a representative intended task and a nearby task that should not select the skill. Follow affected callers to confirm that the current behavior is consistent.

Validate metadata, paths, links, and relevant commands with available tools. Check that group entrypoints expose their rule directory and that moved guidance remains reachable. For imports, verify coverage and retained content against the pinned source, accounting for documented adaptations.

Run changed scripts or verify affected behavior; use formatting and reference checks for prose changes. Report what was verified and any remaining uncertainty. Distinguish structural checks from independent behavioral evaluation, and keep durable rules supported by the result.
