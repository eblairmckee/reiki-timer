# Accessibility and behavior testing

Read the relevant contracts and verification guidance in [rules/](rules/). Identify the expected interaction and choose checks from the changed behavior and the application's installed tools.

Verify the smallest useful behavior, its affected boundaries, and any integration that component tests cannot establish. Report the checks performed, results, and concrete limitations. Distinguish automated evidence from browser inspection and appearance judgments.
