# Layout and content resilience

Timer settings are an unframed sequence over the full-screen atmosphere, with no visible page title. Keep labels and controls in two columns at every viewport size, with descriptions immediately beneath left-aligned labels. Use a centered desktop grid with enough room for the fully configured breakdown example on one line. Let the example use the space up to its switch. At intermediate widths it can span the row beneath the label and control. On mobile, size the control column to fit the dial and its outside value, and give the remaining width to the label and its mixed-case description. Preserve safe-area clearance. Let the tone picker span both mobile columns. Arrange the six choices in one row when they fit, and use balanced rows of three when space is tight.

Give top-level settings rows a common minimum height based on the session dial and enough room for wrapped copy at narrow widths. Center each parent control at the same position in both disclosure states. Place its indented children underneath with a smaller internal gap. When toggling a field, verify that its control and all preceding rows stay anchored, including when a preview above it gains an icon.

Size the dial independently of its value label. The selected time stays upright outside the rim, aligned with the rotating index at every minute, including minutes between engraved marks. Reserve clearance at the top and bottom of a revealed field. Zero is at twelve o’clock and values increase clockwise.

Keep the setup and editor HUD at the top right. During desktop playback, keep Pause and Resume in that same spot. On phones, place them at the bottom right above the safe area for thumb reach. While the timer runs, offer only Pause, with a two-bar glyph. Pausing opens Finish and Edit to the left of Resume. Keep these actions visible for the entire pause as the pointer or keyboard focus moves between them. Resuming retracts the group. Show the three paused actions as full-size icon targets: Logout05 for Finish, a frosted filled Edit03 pencil for Edit, and Play for Resume. Use the shared finish dialog for both early and natural completion. Keep the TimerReset restart icon visible throughout editing on every screen size, including while focus is in a settings field. In the paused editor, place Restart to the left of Resume in the frosted icon group. If edits put the elapsed time beyond the new duration, offer Restart directly. Move focus to the primary control when Edit disappears. Exiting actions become inert and hidden from assistive technology. Use the hierarchy in [foreground components](foreground-components.md).

Order the summary durations as warm up, session and cooldown in the HUD, previews and playback. Put option indicators after the durations. Confine blur to the padded summary backing. Wrap whole items within the space beside the actions. Reserve space beside the editor summary for the visible actions. On hover, unfold this same surface beneath the stationary summary. List timed changes with a muted timestamp and space between events. The initial session start is implicit. Name chakra transitions with the same chakra names as playback. A configured warm up has a start and a transition into Root. Mark each sounding event with a bell on its row and each silent event with a dot, including when every change rings. Derive markers from the playback cue schedule. When the summary trigger is narrow, let the timeline extend across the available space beneath the HUD so timestamps, event names and bells fit. Keep the timeline open while crossing into its content, allow keyboard focus and Escape, and keep touch taps from latching it open.

Show timer counts down the current phase on `/reiki-on`. Its description previews the starting countdown. The Show breakdown description previews the playback summary. Use the clock icon only in the configuration HUD to indicate that Show timer is enabled; the playback breakdown and its preview omit it. Prefix both examples with “Like:” and use a frosted backing for each. During playback, Show breakdown places the summary beneath the countdown and fades completed phases. With breakdown hidden, label warm up and cooldown beneath the countdown during those phases.

Both edit paths use the same settings on `/reiki-on/edit`. Paused editing offers Resume and Restart. The finish dialog links to the same editor before saving. When editing before saving, show Restart and Save together as icons in the HUD and restore the draft on refresh. Use the play glyph for Save with the accessible name “Save timer”. In a paused edit that glyph resumes with the current settings. Confirming leave clears the tab draft and returns to the saved settings or defaults. Only Save writes the configuration to local storage.

Preserve scrolling, text resizing and zoom. Prefer intrinsic CSS geometry; measure in JavaScript only for interaction. Review framing, alignment and progressive disclosure at the viewport sizes requested for the task.
