# Next.js application work

Confirm the target app uses Next.js, resolve its installed version and router, and read the applicable guidance in [rules/](rules/). Use that app's scripts, configuration, and version-matched documentation.

Keep work within the requested feature, review, or optimization. Caching and prefetch migrations require the matching framework capabilities and an application need; select their rules when that work is in scope. Preserve the app's router, bundler, data, authorization, and freshness contracts.

Verify affected behavior in the running app and use a production build for production-only navigation claims. Report what changed, the evidence, and any unsupported or unverified behavior.
